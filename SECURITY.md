# Security Policy

## Supported versions

Security fixes are released for the latest published version of the
`handelsregister` package.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[team@handelsregister.ai](mailto:team@handelsregister.ai). Do not open a public
issue for a vulnerability until the maintainers confirm that disclosure is
safe.

Include the affected SDK version, a minimal reproduction, and the potential
impact. Never include API keys, Bearer tokens, private company data, or other
credentials in a report. Revoke and replace any credential that may have been
exposed.

The maintainers will acknowledge the report, investigate it, and coordinate a
fix and disclosure timeline with the reporter.
